# LENZ

**One world. Infinite perspectives.**

LENZ is an original, open-source, genre-shifting adventure game concept, co-created from Shayne's dream-game idea and the Enter the Field creative universe.

At the heart of the fiction is **L.E.N.Z.**, the *Laboratory for Experiential Neurorealities and Zoning*: a corporation whose Experience Zones have begun bleeding into each other.

This repository is beginning with a browser-playable proof of concept and a Quest-compatible WebXR experiment. The long-term ambition is a cohesive persistent world that can shift between exploration, horror, dungeon combat, platforming, and investigation, including VR.

**Project status:** initial scaffolding; the first playable implementation is being developed in a feature branch.

## Principles

- One persistent world and player state; genre transitions must matter.
- Accessibility and player comfort are first-class, especially in VR.
- Offline-friendly, static-site architecture; no analytics, login or paywall.
- Original implementation, original narrative, no ripped game assets.
- Source code will be available under the MIT license after the initial prototype lands.

Created by the Enter the Field community, inspired by Shayne's concept.
